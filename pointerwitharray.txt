### **1. What will be the output of the following code?**
```c
#include <stdio.h>

void printMessage() {
    printf("Message from function pointer!\n");
}

int main() {
    void (*ptr)() = printMessage;
    ptr();  // Call the function through pointer
    return 0;
}
```
**Answer:**
The output will be:
```
Message from function pointer!
```
Explanation: The function `printMessage` is called using a pointer `ptr` to the function.

### **2. What is the output of the following program?**
```c
#include <stdio.h>

struct Point {
    int x;
    int y;
};

void printPoint(struct Point *p) {
    printf("x = %d, y = %d\n", p->x, p->y);
}

int main() {
    struct Point p = {5, 10};
    struct Point *ptr = &p;
    printPoint(ptr);
    return 0;
}
```
**Answer:**
The output will be:
```
x = 5, y = 10
```
Explanation: The structure `p` is passed to the function `printPoint` using a pointer.

### **3. What will be the output of this program?**
```c
#include <stdio.h>

void multiply(int *a, int *b) {
    *a = *a * *b;
}

int main() {
    int x = 2, y = 3;
    multiply(&x, &y);
    printf("x = %d, y = %d\n", x, y);
    return 0;
}
```
**Answer:**
The output will be:
```
x = 6, y = 3
```
Explanation: The function `multiply` multiplies the values pointed to by `a` and `b`, updating the value of `x`.

    return 0;
}

**Answer:**
