**1.** What will be the output of this program?

```c
#include <stdio.h>
int main() {
    int arr[3][3] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
    printf("%d", *(*(arr + 1) + 1));
    return 0;
}
```

**Output:**
```
5
```
**Explanation:** `*(arr + 1)` points to the second row of the array, and `*(arr + 1) + 1` points to the second element of the second row, which is `5`.
