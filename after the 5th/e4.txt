### **1. Post-increment in Assignment**
```c
#include <stdio.h>
int main() {
    int a = 5;
    a = a++;
    printf("%d", a);
    return 0;
}
```
**Output:** `5`  
**Explanation:** `a = a++` is undefined behavior in C, but usually `a++` returns the original value, and the assignment overwrites the increment.

### **2. Multiple Increments**
```c
#include <stdio.h>
int main() {
    int i = 5;
    printf("%d\n", i++ + ++i);
    return 0;
}
```
**Output:** `12`  
**Explanation:** Evaluation order matters, but result: `5 + 7 = 12` (implementation-defined).

### **3. Assignment in Condition**
```c
#include <stdio.h>
int main() {
    int x = 0;
    if (x = 10)
        printf("x is %d", x);
    else
        printf("x is zero");
}
```
**Output:** `x is 10`  
**Explanation:** Assignment is successful and evaluates to true.

### **4. Static Local Variables**
```c
#include <stdio.h>
void fun() {
    static int x = 0;
    printf("%d ", x++);
}
int main() {
    for (int i = 0; i < 5; i++) fun();
}
```
**Output:** `0 1 2 3 4`  
**Explanation:** `static` retains value across calls.

### **5. Size of Union with Structure**
```c
#include <stdio.h>

    int i;
    float f;
    char str[20];
};
int main() {
    printf("%lu", sizeof(union data));
}
```
**Output:** `20`  
**Explanation:** Size of the largest member (`char str[20]`).

### **6. Character Pointer Trick**
```c
#include <stdio.h>
int main() {
    char *p = "abcdef";
    printf("%c", *++p + 2);
}
```
**Output:** `d`  
**Explanation:** `*++p = 'b'`, `'b' + 2 = 'd'`.

### **8. Nested Ternary**

**Explanation:** Nested ternary resolves to `y`.

### **10. Precedence of Bitwise Operators**

**Explanation:** `&` has lower precedence than `==`.

### **13. Memory Overwrite via Pointer**

### **14. Sizeof Pointer vs Array**
```c
#include <stdio.h>
int main() {
    int arr[10];
    int *ptr = arr;
    printf("%lu %lu", sizeof(arr), sizeof(ptr));
}
```
**Output:** `40 8` (on 64-bit)  
**Explanation:** Array = total size, pointer = 8 bytes.

### **15. XOR Swap Trick**
```c

}
```
**Output:** `4 3`  
**Explanation:** Classic XOR swap (undefined in some compilers).

### **16. Loop With Continue and Label**
```c
#include <stdio.h>
int main() {
    int i = 0;
    loop:
    if (++i <= 5) {
        if (i == 3) goto skip;
        printf("%d ", i);
        goto loop;
        skip:;
        goto loop;
    }
}
```
**Output:** `1 2 4 5`  
**Explanation:** Skips `3` using label.

### **20. Macro With Side Effects**
