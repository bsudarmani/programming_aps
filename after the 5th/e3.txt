### **1. Tricky Integer Overflow**
```c
#include <stdio.h>
int main() {
    unsigned int a = -1;
    printf("%u", a);
}
```
**Output:** `4294967295`  
**Why?**: `-1` gets implicitly cast to unsigned, max `unsigned int`.

---

### **2. Pointer Comparison**
```c
#include <stdio.h>
int main() {
    int a[5];
    if (a == &a)
        printf("Equal");
    else
        printf("Not Equal");
}
```
**Output:** `Equal`  
**Why?**: `a` decays to pointer to `int`, and `&a` is a pointer to the array — in this context, both point to the same address.

---

### **3. Comma Operator Weirdness**
```c
#include <stdio.h>
int main() {
    int x = (1, 2, 3);
    printf("%d", x);
}
```
**Output:** `3`  
**Why?**: Comma operator evaluates all but returns the last value.

---

### **4. Dereferencing Void Pointer**
```c
#include <stdio.h>
int main() {
    void *ptr;
    int x = 10;
    ptr = &x;
    printf("%d", *(int*)ptr);
}
```
**Output:** `10`  
**Why?**: You must cast a `void*` before dereferencing.

### **5. Memory Alignment Pitfall**
```c
#include <stdio.h>
struct A {
    char c;
    int i;
};
int main() {
    printf("%lu", sizeof(struct A));
}
```
**Output:** `8`  
**Why?**: Padding for memory alignment.

---

### **6. Ternary Lvalue**
```c
#include <stdio.h>
int main() {
    int a = 5, b = 10;
    (a > b ? a : b) = 20;
    printf("%d %d", a, b);
}
```
**Output:** `5 20`  
**Why?**: `(a > b ? a : b)` returns `b`, an lvalue.

---

### **7. Overwriting Return Address**
```c
#include <stdio.h>
void func() {
    int a;
    int *ptr = &a + 2;
    *ptr = 0;
}
int main() {
    func();
    printf("Hello");
}
```
**Output:** May crash  
**Why?**: You're corrupting stack memory, possibly return address.

### **8. sizeof on Array Parameter**
```c
#include <stdio.h>
void fun(int arr[]) {
    printf("%lu", sizeof(arr));
}
int main() {
    int arr[10];
    fun(arr);
}
```
**Output:** `8` (on 64-bit)  
**Why?**: `arr[]` decays to pointer when passed to function.

### **25. Pointer Arithmetic on Struct**
```c

```
**Output:** `2`  
**Why?**: `p++` moves by size of struct.
