**1. Pointer Arithmetic and Array Indexing**

```c
#include <stdio.h>

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int *ptr = arr;
    printf("%d\n", *(ptr + 3));
    printf("%d\n", ptr[3]);
    printf("%d\n", 3[ptr]);
    return 0;
}
```

**Output:**
```
40
40
40
```

**Explanation:**
- `*(ptr + 3)`, `ptr[3]`, and `3[ptr]` all access the fourth element of the array, which is `40`. In C, `ptr[i]` is equivalent to `*(ptr + i)`, and due to commutativity, `i[ptr]` is also valid and equivalent.

**2. Function Pointer with Variable Arguments**

```c
#include <stdio.h>
#include <stdarg.h>

void func(int n, ...) {
    va_list args;
    va_start(args, n);
    for (int i = 0; i < n; i++) {
        printf("%d ", va_arg(args, int));
    }
    va_end(args);
}

int main() {
    void (*fp)(int, ...);
    fp = func;
    fp(3, 10, 20, 30);
    return 0;
}
```

**Output:**
```
10 20 30
```

**Explanation:**
- A function pointer `fp` is assigned to `func`, which accepts a variable number of arguments. Calling `fp(3, 10, 20, 30)` invokes `func` with three arguments, printing them sequentially.

**3. Structure Padding and Sizeof Operator**

```c
#include <stdio.h>

struct A {
    char c;
    int i;
    short s;
};

int main() {
    printf("%zu\n", sizeof(struct A));
    return 0;
}
```

**Output:**
```
12
```

**Explanation:**
- The structure contains members with different data types. Due to padding for alignment:
  - `char c` takes 1 byte.
  - 3 bytes of padding are added to align the next `int` to a 4-byte boundary.
  - `int i` takes 4 bytes.
  - `short s` takes 2 bytes.
  - 2 bytes of padding are added to make the total size a multiple of the largest member's alignment requirement (4 bytes).
- Total size: 1 + 3 (padding) + 4 + 2 + 2 (padding) = 12 bytes.

**4. Bitwise Operations and Conditional Statements**

```c
#include <stdio.h>

int main() {
    int x = 5; // 0101 in binary
    int y = 9; // 1001 in binary
    if ((x & y) == (x ^ y)) {
        printf("Equal\n");
    } else {
        printf("Not Equal\n");
    }
    return 0;
}
```

**Output:**
```
Not Equal
```

**Explanation:**
- `x & y` performs a bitwise AND: `0101 & 1001 = 0001` (1 in decimal).
- `x ^ y` performs a bitwise XOR: `0101 ^ 1001 = 1100` (12 in decimal).
- Since 1 is not equal to 12, the output is "Not Equal".

**5. Recursive Function with Static Variable**

```c
#include <stdio.h>

void recursive_func(int n) {
    static int count = 0;
    if (n > 0) {
        count++;
        recursive_func(n - 1);
    } else {
        printf("%d\n", count);
    }
}

int main() {
    recursive_func(5);
    return 0;
}
```

**Output:**
```
5
```

**Explanation:**
- The static variable `count` retains its value across recursive calls. It increments with each call until `n` becomes 0, at which point it prints the count, which is 5.

**6. Dangling Pointer Dereferencing**

```c
#include <stdio.h>
#include <stdlib.h>

int* create_array() {
    int arr[5] = {1, 2, 3, 4, 5};
    return arr;
}

int main() {
    int *ptr = create_array();
    printf("%d\n", ptr[0]);
    return 0;
}
```

**Output:**
```
Undefined Behavior
```

**Explanation:**
- The function `create_array` returns a pointer to a local array `arr`. Once the function returns, `arr` goes out of scope, and `ptr` becomes a dangling pointer. Dereferencing it leads to undefined behavior.

2 8
3 7
4 6

**Explanation:**

**9. Conditional Operator with Side Effects**

```c
#include <stdio.h>

int main() {
    int a = 5, b = 10;
    int result = (a > b) ? a++ : b++;
    printf("%d %d %d\n", a, b, result);
    return 0;
}
```

**Output:**
```
5 11 10
```

**Explanation:**
- Since `a` is not greater than `b`, the conditional operator evaluates to `b++`. The value of `b` before incrementing (10) is assigned to `result`. After the operation, `b` becomes 11.
