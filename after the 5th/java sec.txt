### ✅ 1. Infinite Recursion with try-finally
```java
class Test {
    public static void main(String[] args) {
        System.out.println(test(1));
    }

    static int test(int i) {
        try {
            return test(i++);
        } finally {
            System.out.println("Finally " + i);
        }
    }
}
```
