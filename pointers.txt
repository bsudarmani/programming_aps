## **Function Pointers (10 Questions)**  
### **1. Basic Function Pointer**
```c
#include <stdio.h>
void display() { printf("Hello\n"); }
int main() {
    void (*ptr)() = display;
    ptr();
    return 0;
}
```

### **3. Array of Function Pointers**
```c

```

### **4. Function Pointer Returning Pointer**
```c

    val = x * 2;
    return &val;
}
int main() {
    int *(*ptr)(int) = getVal;
    printf("%d\n", *ptr(5));
    return 0;
}
```

### **10. Function Pointer with Dynamic Memory**
```c

int main() {
    void (**dptr)() = malloc(sizeof(void (*)()));
    *dptr = printMessage;
    (*dptr)();
    free(dptr);
    return 0;
}
```

}

### **18. Dynamic Memory with Double Pointers**
```c

    **ptr = 99;
    printf("%d\n", **ptr);
    free(*ptr);
    free(ptr);
    return 0;
}
```
