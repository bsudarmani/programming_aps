### **1. What is the output of this program?**
```c
#include <stdio.h>

void swap(int *x, int *y) {
    *x = *x + *y;
    *y = *x - *y;
    *x = *x - *y;
}

int main() {
    int a = 5, b = 10;
    swap(&a, &b);
    printf("a = %d, b = %d\n", a, b);
    return 0;
}
```

**Answer:**  
```
a = 10, b = 5
```

Explanation: The `swap` function swaps the values of `a` and `b` without using a temporary variable.

### **2. What will the following code output?**
```c
#include <stdio.h>

void reverseArray(int arr[], int size) {
    int start = 0, end = size - 1;
    while (start < end) {
        int temp = arr[start];
        arr[start] = arr[end];
        arr[end] = temp;
        start++;
        end--;
    }
}

int main() {
    int arr[] = {1, 2, 3, 4, 5};
    reverseArray(arr, 5);
    for (int i = 0; i < 5; i++) {
        printf("%d ", arr[i]);
    }
    return 0;
}
```

**Answer:**  
```
5 4 3 2 1
```

Explanation: The function `reverseArray` reverses the array in place.
