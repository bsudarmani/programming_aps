## **Basic Nested Loops (Logic & Patterns)**  
### **1. Simple Square Pattern**  
```c

    for (int j = 1; j <= 4; j++) {
        printf("* ");
    }
    printf("\n");
}
```

## **Number Series with Nested Loops**

```c
    for (int j = 1; j <= i; j++) {
        printf("%d ", num++);
    }
    printf("\n");
}
```

### **5. Pascal’s Triangle**  
```c
for (int i = 0; i < 5; i++) {
    int num = 1;
    for (int j = 0; j <= i; j++) {
        printf("%d ", num);
        num = num * (i - j) / (j + 1);
    }
    printf("\n");
}
```
🔹 *Modify it to display a binary triangle.*

## **Logic-Based Nested Loops**  
### **7. Print Prime Numbers in a Square Grid**  
```c
int count = 0, num = 2;
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        while (1) {
            int flag = 1;
            for (int k = 2; k * k <= num; k++)
                if (num % k == 0) { flag = 0; break; }
            if (flag) { printf("%d ", num++); break; }
            num++;
        }
    }
    printf("\n");
}
```

### **9. Magic Square (Odd Order)**  
```c
int n = 3;
int magic[n][n], i = 0, j = n / 2;
memset(magic, 0, sizeof(magic));
for (int num = 1; num <= n * n; num++) {
    magic[i][j] = num;
    i--, j++;
    if (num % n == 0) i += 2, j--;
    else if (j == n) j = 0;
    else if (i < 0) i = n - 1;
}
for (i = 0; i < n; i++) {
    for (j = 0; j < n; j++) printf("%2d ", magic[i][j]);
    printf("\n");
}
```
🔹 *Modify it for even `n`.*

## **Nested Loops with Strings**  
### **10. Palindrome String Pyramid**  
```c
char str[] = "HELLO";
int len = strlen(str);
for (int i = 0; i < len; i++) {
    for (int j = 0; j <= i; j++) printf("%c", str[j]);
    for (int j = i - 1; j >= 0; j--) printf("%c", str[j]);
    printf("\n");
}
```
🔹 *Modify to print a mirrored diamond.*
